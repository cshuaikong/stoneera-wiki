## 只有木材预览时，Dirt 在哪里？

打开 **Build → Blocks**，再点击 **Block 卡片本身**。木材预览不是完整的材质选择器。[开发者11月4日回复](https://steamcommunity.com/app/5057770/discussions/0/569302110932348639/#c569302110932369100)说明：点击后会打开列表，向下查找 **Dirt** 并选中，再点击地面缺口创建放置订单。不要因为卡片还画着木头，就判断泥土建造不存在。

![原创泥土材质选择与建造订单流程示意图，非游戏画面](/images/articles/dirt-blocks.webp)

原问题来自一位想填补农场缺口的玩家：他在方块选项中只看到了木材。因此优先要解决的是找到真正的材质列表。Demo 0.9.18 也调整了 Build，将 Orders、Buildings、Blocks 和 Objects 放在一起；旧截图与当前菜单不同，并不自动意味着进入了另一种游戏模式。

## 怎样从选择材质变成实际填好缺口？

选中 Dirt 后，标记需要填补的位置，并区分新订单与已经完成的地形。开发者对普通模式给出的条件是仓库中有泥土，以及可用 Builder；Creative 则会立即放置。如果用 Creative 的即时表现来判断普通模式，很容易把正常等待施工的订单误认为功能失效。

1. 从 Build 打开 Blocks。
2. 点击 Block，打开列表并选择 Dirt。
3. 标记本次想填补的具体缺口。
4. 普通模式下，检查泥土库存与 Builder 是否可用。
5. 观察订单完成后缺口是否真正填好。只看到材质被选中，不能证明施工已经结束。

这里没有指定通用快捷键、画笔尺寸或固定资源消耗。应查看当前版本显示的选择范围。创建较大区域订单前，先确认实际标记了哪里，避免把错误选区与工人没有执行混为同一个问题。

## 点击后没有变化，应该先检查什么？

先辨认三种不同状态：列表里没有材质、根本没有创建订单、已有订单在等待施工。第一种应按开发者要求报告版本与模式；最后一种可以通过[停工检查指南](/zh/building/stalled-construction/)阅读项目反馈，而不是无差别重复点击所有可见选项。

| 看到的情况 | 有用的下一步 |
| --- | --- |
| Block 卡片仍显示木头 | 点击卡片本身，进入真正的材质列表。 |
| Dirt 已选中，地面没变 | 检查是否放下了订单，以及当前是 Normal 还是 Creative。 |
| 普通模式订单一直等待 | 检查泥土库存、Builder 和项目显示的阻碍。 |
| 总库存有材料，项目仍缺货 | 查看[仓储接收与搬运](/zh/colonists/storage-filters-and-hauling/)，不要只看总数。 |
| 材质列表确实没有 Dirt | 记录版本和模式，在原帖反馈。 |

来源没有说明 Dirt 需要某项特殊研究，也没有给出材质缺失的保证修复方法。不要为了强制出现选项而删除殖民地。如果实际目标是移除已有地面，而不是填补缺口，先阅读[拆除与移动的区别](/zh/building/deconstruct-and-move/)。

## 这些步骤适用于哪个版本？

本文是 Demo 0.9.18 时期的资料整理，于2026年11月6日核对。菜单公告与有日期的开发者回复支持上述步骤，不代表本站做过实机测试。完整游戏是否发售是另一项状态，本文也不保证所有后续版本永远使用相同标签。
